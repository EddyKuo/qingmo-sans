# 晴墨黑體 Design Spec v0

Oct 28, 2026 · @Eddy Kuo

## 定位與目標

晴墨黑體（Qingmo Sans TC）是以 SIL OFL 1.1 釋出的繁體中文「明黑混合」內文字型：黑體的骨架與清晰度，加上明體的書寫筆勢，主戰場是 10–16 pt 的螢幕與印刷內文。0.102 起在「點、提、鉤」等筆畫加入含蓄的小楷筆意（見「楷書筆意」）。

- **使用情境**：App/Web UI 內文、長篇閱讀、簡報、品牌輔助字
- **v1.0 目標**：Big5 完整字集 + 教育部常用字、6 個字重的 Variable Font、橫排與直排
- **非目標（v1）**：強烈個性的標題展示字、簡體字集、完整的手寫或書法風格（只取小楷筆意，骨架仍是黑體）、hinting 完整度

## Clean-room 規範

所有字形只能源自 OFL 母體與本專案自己的參數、程式碼；任何第三方商用字型的字形資料一律不進入 repo、建置流程或模型。

| 類別 | 規則 |
| --- | --- |
| 禁止 | 開啟、擷取、描繪、比對任何商用字型檔（含 jf 金萱）的 outline；以其字樣訓練或提示任何生成模型；名稱或宣傳使用「金萱」 |
| 允許來源 | Source Han Sans VF（OFL）、本 Spec 的參數、公開文獻中的文字描述 |
| 允許參考 | 字型設計通論（中宮、重心、筆勢等概念）；視覺審查僅限人眼，不存檔、不入版控 |
| 紀錄 | 每個參數變更寫入 `FONTLOG.txt` 與 commit message；`CLEANROOM.md` 由每位貢獻者簽署 |

## 風格參數

設計意象：「晴」= 骨架方正、留白均勻（0.101 前為「中宮開朗」）；「墨」= 筆畫有明體的粗細對比與墨暈般的軟角。以下數值為 Regular（wght 400）的 v0 初值，Phase 1 以實際字樣調整。

| 參數 | v0 初值 | 實作方式 |
| --- | --- | --- |
| 字身比例 | 方正，寬高比 1.00 | 不做整字縮放 |
| 中宮 | ~~比母體放鬆 3%~~ → 0.101：比母體收緊，`counter_open_pct: -25`（部件最多內移約 31 units） | per-component 內移，保持部件筆畫粗細 |
| 重心 | ~~居中，上移 ≤ 0.5%~~ → 0.101：字身中段上移 2%（20 units） | 上下結構字調整部件高度比 |
| 筆畫對比（豎 : 橫） | 100 : 82 | 依筆畫方向做非對稱 offset |
| 起筆 | 斜切 12° | terminal 幾何重建 |
| 收筆 | 微收 8% 寬度 | 末端 taper |
| 折角 | 外角軟化 r = 6 units（UPM 1000） | corner rounding，隨字重縮放 |
| 點 | 上尖下圓的錐形點 | 點類筆畫模板替換 |
| 捺 | 收尾帶短平台再出鋒 | 捺類筆畫模板替換 |
| 撇 | 出鋒漸細，末端不留尖刺 | taper + 最小寬度限制 |
| 提（0.102） | 起筆頓按加寬、圓頭，往右上挑出尖鋒 | 提類筆畫模板替換 |
| 長點（0.102） | 起筆輕尖，往右下漸按，收筆圓厚 | 長點類筆畫模板替換 |
| 鉤（0.102） | 鉤前頓筆、往內側收成尖鋒並上挑 | 鉤類筆畫模板替換 |

### 楷書筆意（0.102，維護者核可）

**緣由**：2026-10-29，維護者檢查 0.101 時，認為長點（例如「凶」的乂右筆、「涷」裡「東」的末筆）和提（例如「涷」的氵末筆）缺少小楷的韻味，要求加入楷書筆意；同日要求鉤的所有種類一併完成。

**依據**：只採用書法文獻的文字描述，不參考任何字型的字形。永字八法把楷書筆畫分為側（點）、勒（橫）、努（豎）、趯（鉤）、策（提）、掠（長撇）、啄（短撇）、磔（捺）；楷書的韻味來自毛筆的提按，同一筆畫的粗細會沿著筆畫變化。

**強度**：含蓄。內文字級下看得出筆意，但不改變黑體的骨架與清晰度。

| 筆畫 | 辨識（在參考 master 上，母體輪廓） | 模板 |
| --- | --- | --- |
| 提（策） | 4 段直筆、兩端皆直線 cap；左下往右上 5°–75°（5°→25° 強度漸增）；長 0.25–0.48 UPM；左下端在字寬 45% 以內（左偏旁） | 起筆 cap 加寬並插入圓頭（頓按），尖端收窄出鋒 |
| 長點（側） | 4 段筆畫；左上往右下 −70°～−20°；長 0.42–0.85 UPM（比點長）；頂端為直線 cap；尾端為直線 cap，或為曲線 cap 且兩側為直線（與捺區分） | 頂端收尖，尾端加寬並插入圓頭 |
| 鉤（趯） | 曲線 cap、輪廓在此折返（前後切線夾角 > 120°）、所在輪廓至少 6 段（鉤與前一筆連成一體）；鉤尖朝左（±160°–180°：豎鉤、彎鉤、橫折鉤）或朝右上 20°–100°（臥鉤、斜鉤、豎彎鉤、豎提） | 鉤尖往內側（凹側）端點收窄出鋒；外側邊的控制點跟著上挑；鉤前轉彎的外緣往外鼓（頓筆） |

鉤的內側端點：朝左的鉤取較高的一端，朝右上的鉤取較左上的一端，也就是筆畫轉彎的凹側。宀、冖的橫鉤朝左下，已經落在撇的出鋒規則裡，不另外處理。朝下的筆端（月字旁的豎撇）和朝右的筆端（辶的平捺）不是鉤，不套用。

**強度漸增與近垂直的點**（2026-10-29，維護者回報金字旁與糸、灬）：同一個部件的筆畫朝向在不同字裡會差 1–3°，硬門檻會讓同部件一個字有、一個字沒有（金字旁的提 11–14°、內點離垂直 11–14°，都跨過舊的 12° 門檻）。因此：
- 提的朝向 5°→25° 強度由 0 增加到 1，寬度比例與圓頭凸出依強度往「不變」內插；平緩的提（金、虫、王）只帶少許筆意
- 近垂直的點：母體的豎畫離垂直正好 0°，所以離垂直超過 0.2° 的短筆（≤ 0.26 UPM）就是點，套完整強度。糸、灬（含馬、魚、鳥）、忄、立的點離垂直只有 0.4°–12°，舊規則下保留直角收尾
- 近水平的點：離水平 8°→25° 漸強（女的長橫約 3°，不是點）

楷書中常見「捺縮成點」：例如囚的人、季的禾、逢的夂，以及女的撇點。這些筆畫在母體裡多半是直的長點形狀，會被辨識為長點，這和楷書的寫法一致。

## 差異化定義

晴墨與金萱同屬「明黑混合」類型，但在 5 個可辨識的維度上刻意走不同方向；比較依據僅限 justfont 公開文章對金萱的文字描述（瘦長骨架、中宮緊收、重心偏上）。

| 維度 | 金萱（公開描述） | 晴墨決策 |
| --- | --- | --- |
| 骨架比例 | 瘦長 | 方正，偏 UI 可讀性 |
| 中宮 | 緊收 | 0.101 起收緊（維護者核可，見下方） |
| 重心 | 偏上 | 0.101 起略上移 2% |
| 折角 | — | 墨暈軟角，作為晴墨的識別特徵 |
| 筆端 | — | 統一 12° 斜切 + 捺筆短平台，自有規則；0.102 起提、長點帶小楷提按 |

任何參數若被調整到接近左欄描述，須在 PR 中說明理由並經維護者核可。

**0.101 核可紀錄（2026-10-29，維護者 Eddy Kuo）**：維護者目視 0.100 後認為「整體太鬆、太散」。公開文獻的文字描述指出，傳統漢字多半中宮緊收、重心偏高；中宮放鬆、重心降低是受拉丁 glyph 影響的取向，會讓字少了漢字韻味，而中宮緊收能讓外輪廓更清楚、更好認（柯熾堅，inside 專欄與 justfont 部落格）。這是通論，不是金萱獨有的特徵，所以維護者核可中宮、重心兩欄往緊收、偏上調整。晴墨和金萱的差異改由其餘三個維度維持：方正骨架（金萱是瘦長）、墨暈軟角，以及自有筆端規則。參數值由 phase1 字集的多組校樣目視選定，過程見研究紀錄 §12。

## 母體與授權

母體採 Source Han Sans TC 的 Variable 版本：字集涵蓋繁體需求，且各 master 點相容，改造後可直接輸出 wght 可變字型。

- **授權**：衍生作品必須維持 SIL OFL 1.1；不得單獨販售字型檔，可隨軟體散布
- **Reserved Font Name**：母體保留 "Source"，晴墨的任何名稱欄位（`name` table ID 1/4/6/16）不得出現此字
- **版權聲明**：`OFL.txt` 同時列出 Adobe 原始版權（含 RFN 聲明）與晴墨貢獻者版權
- **主要技術風險**：每一步幾何改造都必須保持跨 master 的點數與順序一致，否則 VF 插值失效；Phase 1 的首要驗收即為此
- **已確認（Phase 1）**：母體 VF 的 wght 範圍為 250–900，named instances 250 / 300 / 350 / 400 / 500 / 700 / 900，並有非線性 `avar`；晴墨沿用該字重曲線

## 字重與度量

單一 wght 軸的 Variable Font，另輸出 6 個 static instances；度量沿用母體，避免與既有排版習慣衝突。

| 項目 | 規格 |
| --- | --- |
| 可變軸 | `wght` 250–900（母體 `fvar` 範圍；Phase 1 定案） |
| Named instances | ExtraLight 250 · Light 300 · Regular 400 · Medium 500 · Bold 700 · Heavy 900（ExtraLight 的 usWeightClass 仍為 200） |
| 中文字重名 | 極細 · 細 · 標準 · 中 · 粗 · 特粗 |
| UPM | 1000 |
| 漢字字寬 | 全形 1000 units |
| 字面框 | 沿用母體 ICF：ideo 基線 -120；icfb / icft = -67 / 827（wght 250）、-78 / 838（400）、-94 / 854（900） |
| 直排 | 保留 `vhea` / `vmtx` 與 `vert` / `vrt2` feature；標點直排字形一併改造 |
| 拉丁字母 | v1 沿用母體內含字形，僅做字重對齊；v2 評估自製 |
| 輸出格式 | TTF（VF + static）、WOFF2；OTF/CFF2 於 v1.0 再評估 |

名稱已做初步網路查核（同名字型、品牌皆未發現），正式發布前仍須完成 TIPO 第 9、16 類近似檢索。

| 欄位 | 值 |
| --- | --- |
| Family（中 / 英） | 晴墨黑體 / Qingmo Sans TC |

| VF 檔名 | `QingmoSansTC[wght].ttf` |
| Repo | `qingmo-sans` |
| License | SIL OFL 1.1 |

每個 release 必須全數通過：

- [ ] 跨 master 點相容 100%（VF 可編譯、插值無破形）
- [ ] 破字 0：無自交、方向錯誤、殘留 overlap（skia-pathops 檢查）
- [ ] 灰度一致：同結構類別的字面墨色覆蓋率標準差低於門檻（Phase 1 定門檻值）
- [ ] fontbakery 無 FAIL
- [ ] 12 / 16 / 24 px 全字表渲染人工抽檢高頻 500 字
- [ ] `name` table 不含 "Source"
